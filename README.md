## Project
A responsive portfolio site that practices CSS layout, typography, color, forms, and interaction states.

## Pages
- `index.html` — responsive portfolio home and side-image hero
- `about.html` — background and skills
- `project.html` — responsive project cards and button variants
- `contact.html` — responsive contact form and sidebar
- `box-model-practice.html` — box model visualization and card exercise
- `flexbox-practice.html` — navigation, equal-height wrapping cards, and footer columns
- `image.html` — six-image Grid gallery and magazine layout
- `hero-practice.html` — full-screen image-overlay hero

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, custom properties, and media queries)
- Google Fonts: Poppins and Roboto

## Run locally
Open `index.html` in a browser, or open this folder in VS Code and start Live Server.

## Responsive checks
The layout is designed for 320px, 768px, 1024px, and 1440px widths.
